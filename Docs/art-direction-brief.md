# 主角美术与技术基线

以 `Producer_Ref` 四视图为形象依据：成年男性、长黑发与胡须、深海军蓝内衬、深棕皮革、冷灰金属片甲、粗糙毛领和不对称长披风。优先保留毛领肩线、胸前斜带、腰带与护腿的识别轮廓。

场景采用中性石材与暖色侧光，角色的蓝色衣物、皮革与金属需要保持独立的明度和粗糙度响应。环境是用于运动、镜头碰撞与角色材质检查的建筑测试场；不把它视为完成的影视级关卡。

角色身高基线 186 cm，Z 向上。源 FBX 的网格与骨骼数据使用厘米单位，根骨骼比例为 1。导入后的角色参考姿态朝 +Y，运行时网格偏航 -90° 以匹配 Character 的 +X 前方。所有 Python Rotator/Color 使用命名参数。

默认镜头臂长 350 cm，水平 FOV 68°；聚焦臂长约 235 cm，FOV 55°；左右肩偏移平滑切换。当前目标是全身移动与过肩聚焦的可操作基线，近景面部评审另做专门镜头。

PBR 贴图为 4K Base Color、Normal、Roughness、Metallic。颜色使用 sRGB，其余数据使用线性空间；从 Blender 的法线工作流进入 UE 时翻转法线绿通道。当前材质未拆成专门的皮肤、头发、布料和金属着色模型。

已有源文件、云端结果和 UE 资产分别保存，技术通过不等于美术定稿。后续需要修正披风蒙皮、肩髋形变、手指、发型与面部，以及脚部接触和移动转换。

v0.2 保留身体网格、原 22 骨参考姿态与原 UV，追加 9 根后部披风骨并平滑重分配披风权重。披风的跑动拖曳、转身惯性与轻微风动由有阻尼的骨链实现；极端姿态碰撞与独立布料网格仍待制作。现行材质 `M_Hero_V02` 对深蓝织物增加导数滤波微法线和更哑光的粗糙度，沿用原 4K 贴图，没有把颜色推断区域称为人工精绘的材质分区。

评审场景的石材使用低对比度、约 83/42 cm 的两层空间变化，Noise 输出限制为 0–1。所有材质连接检查返回值，避免位置节点失连后回到厘米级噪点。坡道/跨阶评审相机应同时包括双脚和地面；近景与运动图分别评审，不能用遮住脚底的构图证明接地。
